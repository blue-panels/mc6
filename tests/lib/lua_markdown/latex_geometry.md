**Идея решения:**
Кажется, что данных не хватает, но здесь работает классический трюк для трапеций с неизвестными углами — **проведение линии, параллельной боковой стороне**.
1. Из вершины $C$ проведем отрезок $CE$, параллельный стороне $AD$ (точка $E$ лежит на $AB$).
2. Фигура $AECD$ — параллелограмм. Значит, $AE = CD = 15$ и $CE = AD = 10$.
3. Углы параллелограмма: так как $\angle CDA = 104^\circ$, соседний с ним угол $\angle DAE = 180^\circ - 104^\circ = 76^\circ$.
4. Так как $AD \parallel CE$, то соответственный угол $\angle CEB = \angle DAE = 76^\circ$.
5. Рассмотрим треугольник $\triangle CEB$. В нем известны два угла: $\angle CEB = 76^\circ$ и $\angle EBC = 52^\circ$ (по условию). 
   Найдем третий угол: $\angle ECB = 180^\circ - (76^\circ + 52^\circ) = 52^\circ$.
6. Получилось, что $\angle ECB = \angle EBC = 52^\circ$. Значит, $\triangle CEB$ — **равнобедренный**! Следовательно, $EB = CE = 10$.
7. Ищем всю базу: $AB = AE + EB = 15 + 10 = 25$.
**Ответ:** $AB = 25$.
