# НАЗИВ

mdiff - Уграђени diff прегледач ГНУ-овог поноћног наредника..

# УПОТРЕБА

**mdiff**
[-bcCdfhstVx?] дато1 дато2

# ОПИС

mdiff је веза ка
**mcommander**-у,
главној извршној датотеци ГНУ-овог поноћног наредника. Извршавање ГНУ-овог
поноћног наредника под овим именом захтева покретање уграђеног diff прегледача,
који пореди
*дато1*
са
*дато2,*
задатим у командној линији.

# ОПЦИЈЕ

*-b*
: Намеће црно-бели приказ.

*-c*
: Намеће колор режим на терминалима на којима је
**mdiff**
подразумевано црно-бео.

*-d*
: Деактивира подршку за миша.

*-f*
: Приказује укомпајлиране путање за претрагу за датотеке Поноћног наредника.

*-S арг, --skin=арг*
: Задаје назив скина у командној линији.

*-t*
: Користи се само ако је код компајлиран са S-Lang-ом и terminfo-ом: чини да
Поноћни наредник користи вредност променљиве
**TERMCAP**
за информације о терминалу уместо информација из системске базе терминала

*-V*
: Приказује верзију програма.

*-x*
: Намеће xterm режим. Користи се на терминалима сагласним са xterm-ом (два
екранска режима и способност за слање ескејп секвенци миша).

# ДАТОТЕКЕ

*{{pkgdatadir}}/help/mcommander.md*
: Датотека помоћи за овај програм.

*{{pkgdatadir}}/mc.ini*
: Подразумевана системска подешавања ГНУ-овог Поноћног наредника, која се користе
само ако не постоји корисничка датотека ~/.config/mc6/ini.

*{{pkgdatadir}}/defaults.ini*
: Глобална подешавања Поноћног наредника. Подешавања у овој датотеци утичу на све
кориснике, без обзира на то да ли имају ~/.config/mc6/ini или не.

*~/.config/mc6/ini*
: Корисничка подешавања. Ако је ова датотека присутна, онда се подешавања
учитавају одавде уместо из системске датотеке са подешавањима.
